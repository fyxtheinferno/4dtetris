Each viewport is a cross section of 4d space along the w-axis. Fill a 3D cross section (x, z, w) along the y-axis (vertical) to clear a line
## Controls
`: hold piece
Shift: soft drop
Space: hard drop
click & drag piece view: rotate camera
arrow keys: move along X/Z axes
N, M: move along W axis
Q: rotate along WX plane
A: rotate along WY plane
Z: rotate along WZ plane
E: rotate along XY plane
D: rotate along XZ plane
C: rotate along YZ plane
